# 0.6.0 横向渐变与自定义背景图

直接覆盖安装0.5.0，打开应用进入“配色与外观”。

## 参考图渐变

“背景类型”选择“横向粉紫蓝渐变”。渐变沿水平方向从左侧粉紫、浅蓝过渡到右侧白色，不再沿对角线做很浅的色彩变化。

建议先设：渐变色彩强度85–100%、背景明暗度50、背景不透明度100%。这样最容易看清参考图的左右色彩变化，再按壁纸调整透明度。亮度调至最右会接近纯白，调至最左会接近纯黑，属于正常行为。

## 自定义背景图

1. 点击“选择 / 更换背景图”，通过系统相册或文件选择器选图。
2. 导入成功后自动切换到“自定义背景图”。应用只读取选择的这一张图，不申请整个相册的访问权限。
3. 图片自动铺满圆角卡片，先调缩放，再调水平和垂直位置。缩放100–300%，位置50%为居中；保持铺满，不会移动出空白边。
4. 明暗度、透明度、文字颜色、分隔线与网格设置都继续生效。照片较花时，可使用白色文字配暗背景，或黑色文字配亮背景。
5. “重置图片位置”恢复居中；“移除背景图”只删除应用内副本，不影响相册原图。

图片会处理方向并缩小保存到应用私有目录，长边最多1600像素。重启、覆盖升级、移动或删除相册原图不影响已保存背景；卸载或清除应用数据会删除该副本。此前无照片时的数据结构保持兼容。

同一套背景设置应用于所有桌面实例。松开滑块后更新预览与桌面，无需额外保存。照片选择器和实际显示效果仍需在真机确认。
