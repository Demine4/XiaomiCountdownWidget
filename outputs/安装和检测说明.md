# 倒数日读取检测版 0.1.0

本版用于确认小米 17 Pro Max / 澎湃 OS 3 是否向普通应用开放原有倒数日数据，暂不包含桌面小部件。

1. 将同目录 APK 传到手机，点击安装，按系统提示允许该来源安装。
2. 打开“倒数日读取检测”，点击“授权并开始检测”，允许读取日历。
3. 搜索小米日历中一条已知倒数日的标题。可以新建“组件测试-未来”避免暴露私人内容。
4. 点击匹配结果，核对日期，然后点击“复制去内容字段报告”。
5. 将该报告和主页面“复制不含标题的检测摘要”的内容反馈到聊天里，并说明它是一次性还是重复倒数日。发送前检查属性名和 JSON 键中是否存在私人内容。

如果找不到，请直接反馈“读取成功但找不到”或显示的失败原因。普通日程能读到不等于倒数日兼容成功。

“复制完整字段”可能含私人信息，需要额外确认；目前优先使用去内容报告。

应用只有日历读取权限，无联网权限，不修改、删除日程，不自动发送任何数据。尚未在你的真实手机上测试；APK 的编译、签名及对齐已在电脑验证。
