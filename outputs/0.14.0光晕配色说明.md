# 0.14.0 光晕配色

覆盖安装 XiaomiCountdown-0.14.0.apk，签名和包名沿用旧版。

在应用的“配色与外观”中点击“光晕配色”：

- 使用“增加 / 减少”选择1～4个颜色，点击对应色块调色。
- 每种颜色可以通过红绿蓝滑块调整，也可以输入 #RRGGBB 色值。
- 配色窗口预览当前光晕，点击“应用”保存并切换至光晕背景；“取消”保留原设置。
- “恢复默认”恢复原有粉紫蓝配色；不重置光晕位置、范围、强度和消散速度。
- 减少颜色数量会隐藏末尾的颜色，再增加时保留其配色。

修正背景明暗度：光晕背景先调整底色，再绘制光晕，调到0或100不会再被整层黑白遮挡。光晕强弱仍由“光晕色彩强度”控制。

所有设置应用于应用预览和桌面小部件。原来的日历数据、背景图片和其他设置保留。

验证：日历、重复日期、图片裁剪、纪念日与布局测试通过；新增光晕1～4色、默认配色、颜色强度、深色模式、极端明暗度和非法颜色数量测试。APK编译、签名及对齐检查通过。配色操作仍需真机验收。
