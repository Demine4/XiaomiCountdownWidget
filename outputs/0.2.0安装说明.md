# 日历倒数日 0.2.0

## 安装和添加

1. 将 `XiaomiCountdown-0.2.0.apk` 传到手机并安装。包名和签名沿用检测版，可覆盖安装，不用先卸载。
2. 安装后名称变为“日历倒数日”。打开应用，允许读取日历，点“授权 / 刷新”。
3. 检查首页列表：未来及今天的项目在“桌面将显示”；过期的一次性项目在“已过期 · 仅在此查看”。
4. 点“添加到桌面”，按桌面提示确认。若无反应，可在桌面长按 → 添加小部件 → 安卓小部件，找到“日历倒数日”。具体入口名称以手机系统为准。
5. 桌面长按组件可调整大小；应用中可调整背景透明度、字号和最多显示条数，所有组件共用这些设置。

## 数据规则

- 只识别小米日历中具有 `key_countdown_info` 扩展属性的记录，普通日程不混入。
- `repeatType=0`：不重复，目标日期过了当天后从桌面隐藏。
- `repeatType=1`：每月重复，显示下一次发生日期。
- `repeatType=2`：每年重复，显示下一次发生日期。
- 默认显示今天。关闭该开关后，重复事件直接显示下一次，一次性今天事件从桌面隐藏。
- 目标日期使用扩展字段 `timeMillis`，按手机当前时区解释，按自然日计算，不按剩余小时除以24。
- 短月和闰年采用月末补齐：每月31日在2月显示最后一天，3月恢复31日；2月29日的每年重复在非闰年取2月28日。此边界规则尚未与小米日历真机逐项核对。
- 暂不实现农历重复；未知重复类型、缺失或损坏字段会跳过并在首页提示。
- 原记录不删除、不修改，所有操作仅限读取。无网络权限，无常驻后台服务。

## 刷新

首次添加、打开应用、手动点组件右侧 ↻、重启后及系统通知日历变化时尝试刷新，并请求每30分钟周期刷新和次日的非精确刷新。系统省电和后台限制可能造成延迟，不保证午夜整点更新。修改日历后如未及时变化，可点 ↻。

## 请验证

- 新建一条几天后的倒数日，应出现在应用及桌面；修改标题或日期，点 ↻ 应更新。
- 已过期的一次性倒数日不出现在桌面，原记录在小米日历中仍存在。
- 每月、每年倒数日应显示下一次日期。
- 今天到期的记录应遵循开关设置。

日期规则的20项边界测试、APK编译与签名检查已通过。小米真机的桌面效果和后台刷新仍需实际验证；可发送桌面截图继续调整外观。
