# 0.13.0 分区布局，解决纪念日信息挤窄

有纪念日数据时，默认采用上下分区：

- 上方两列：倒数日，以及生日/周期倒数日，每列宽度比三列模式更充裕。
- 下方通栏：纪念日名称和累计天数同排，下一行显示完整原始日期与“距N周年还有N天”。详情不再缩到7sp塞进窄列。
- 名称或详情较长时允许换行，并按宽度及字体大小预留高度。
- 去掉按最大设置填充的大量空白虚线行。高度不够时在标题提示还有多少条，拉高组件即可显示更多。
- 没有纪念日时沿用原有三列布局；关闭应用中的“纪念日通栏显示（推荐）”也可切回三列。

直接覆盖安装并打开应用刷新。已有背景、日期数据、归类和点击跳转设置保留。应用内预览会在通栏模式增高，方便检查排版。

同目录“分区布局示意-0.13.0.png”是使用示例数据绘制的布局示意，背景与应用共用绘制代码；不是手机截图，实际字体与间距以真机为准。

57项检查通过，其中6项空间分配检查包含183组高度/字号组合。APK编译、签名、对齐检查通过，原生日历卡片的实际排版需在小米桌面核对。极长文本仍可能在两行后省略，物理空间不足时会减少显示条数。
