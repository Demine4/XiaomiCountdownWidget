# 0.15.0 三列滚动

直接覆盖安装 XiaomiCountdown-0.15.0.apk。Android 12及以上自动使用新布局，包含你的Android 16手机。

- 保持“倒数日 / 纪念日 / 生日或周期倒数日”三列结构。
- 列标题固定，手指在某一列内上下滑动，该列独立滚动。
- 纪念日按名称、累计天数（结婚记录显示已婚天数）、原始日期、下次周年分别展示。每部分均可自动换行，记录高度随内容增长。
- 两侧的名称和天数或日期也分行显示，名称可换行。
- 展示全部项目，不再按组件高度或旧的15条上限裁掉后续内容。旧的最多行数设置在滚动模式隐藏。
- 点击记录继续打开小米日历，列标题也可打开日历；右上角的小箭头保持刷新功能。
- 保留光晕、1～4色自定义、背景图片、透明度、字号及周期归类设置。

如果覆盖安装后桌面仍显示旧布局，先打开应用刷新；必要时移除桌面小部件再重新添加。可拉高组件以同时看到更多内容。

实现使用Android官方的ListView与RemoteCollectionItems集合接口，不需要新增权限或后台服务。Android 11保留原有静态布局。

验证：现有本地规则测试通过，新增的Android仪器检查覆盖列表条数、滚动能力、纪念日日期可见性及文本换行。Android仪器检查仅编译，未运行；当前模拟器无法正常启动。APK资源、Java编译、签名及对齐检查通过。需要真机核对HyperOS桌面的滑动手势与点击行为。
