# 日历倒数日 0.4.0

直接覆盖安装上一版，然后打开应用一次。

## 本次更新

- 新增紫色日历倒数图标，支持系统图标形状和主题单色图标。
- 补充创建桌面快捷方式的声明与小米权限设置入口。
- “添加到桌面”检查桌面是否支持、是否接受请求，并接收真正添加成功的回调；发出请求不再视为已添加。失败时显示重试及手动添加引导。
- 新增自启动、小米省电策略、Android电池优化豁免设置入口。
- 新增可跨重启保存的30分钟周期刷新任务，保留日历变更触发、桌面周期刷新和次日非精确刷新。
- 显示上次桌面刷新时间与日历读取结果。自启动和小米省电策略无法通过公开API可靠查询，应用不会将“打开过设置页”误报为“已授权”。

## 安装后操作

1. 打开“日历倒数日”，点击“打开桌面权限设置”，在系统页面找到并允许“创建桌面快捷方式”。返回应用，重新点“添加到桌面”，确认桌面的添加提示。
2. 点击“开启自启动”，找到本应用并打开自启动。若未能跳到对应页面，在系统设置中搜索“自启动”或从应用详情进入。不同版本入口可能不同。
3. 点击“小米省电策略：设为无限制”，在系统中选择“无限制”。如果跳转失败，打开的是本应用详情，在其中查找省电策略。
4. 如有需要，点击“申请忽略Android电池优化”，确认系统授权。这个状态与小米的省电策略不是同一个开关。
5. 返回应用点“授权 / 刷新”。在桌面查看小部件；不必让应用界面一直打开。

仍无法通过应用添加时，可长按桌面空白处 → 添加小部件 → 安卓小部件 → 日历倒数日。创建应用快捷方式与添加小部件是两套机制，实际是否弹出确认由小米桌面决定，权限声明不能替代桌面的支持。

## 刷新边界

清理最近任务或系统回收进程后，系统任务可重新调度应用刷新；小米自启动限制、省电和系统调度仍可能造成延迟，30分钟是请求周期，不是准点保证。

在应用详情中点“强行停止”会阻止应用后台运行，任何自启动引导或普通周期任务都无法保证绕过；重新打开应用后会恢复调度。

## 验证情况

日期规则测试、APK编译、签名、对齐及图标/权限声明检查在电脑完成。小米专属设置页跳转、桌面添加权限和后台回收后的刷新效果，仍需在你的澎湃OS3真机确认。
