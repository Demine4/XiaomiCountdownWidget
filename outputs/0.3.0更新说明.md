# 0.3.0 三列表格版

可直接覆盖安装0.2.0。安装后打开应用，点“授权 / 刷新”，桌面组件会更新。旧组件如果太矮，请长按拉高，或移除后重新添加。

## 外观

按提供的参考图改为半透明浅色圆角卡片，去掉大日期栏，三列等宽；灰色列标题，圆点列表，名称与天数同一行，浅色虚线分隔。

默认三列：倒数日、纪念日、周期倒数日。

打开应用中的“第三列显示生日”开关后：倒数日、纪念日、生日。

应用内预览与桌面共用同一套布局，可调整背景透明度、字号和每列行数。字号默认11sp，每列最多5行，实际行数按组件高度自动缩减。长名称在单行末尾省略。

## 数据

- 倒数日：不重复且未过期的记录，显示“今天”或“N天后”。
- 周期倒数日：每月/每年重复，显示下次日期距离今天的天数。
- 纪念日：读取 key_anniversary_info 的 timeMillis，显示过去的自然日天数；尚未到首次日期的显示“N天后”。按原始日期从早到晚排列。
- 生日：读取 key_birthday_info 的 name 和 firstBirthMillis，按下次生日排序，显示MM-dd，不显示年龄。
- 生日与纪念日先支持用户样例中的dateType=0；其他日期类型暂不显示，应用中会提示数量。农历尚未适配。

原日历记录不修改、不删除。今天开关和原有重复日期规则继续用于倒数日。其他数据类别的功能与真机同步情况需要安装后核对。
