# 0.7.0 柔彩光晕

将线性的横向色带替换为多个错开中心、半径和形状的粉、紫、蓝柔光云团，彼此交融并向周围淡出。左上偏粉紫、左下偏浅蓝，右半边保留白色留白，避免整张卡片均匀染色。

覆盖安装后，背景类型选择“柔彩光晕（参考图）”。推荐先用浅色模式、光晕色彩强度85%、明暗度50、不透明度100%查看效果，再按壁纸微调。

原渐变选项会自动使用新的光晕绘制，不必重新添加小部件。自定义照片、数据读取和日历跳转保持现有功能。

同目录“柔彩光晕背景预览.png”是直接用小部件共享的HaloBackground像素绘制代码生成的背景预览，不包含文字和桌面壁纸；手机上的透明度、深浅模式和比例会影响最终观感。此处为静态柔光效果，没有增加持续动画或后台渲染。
