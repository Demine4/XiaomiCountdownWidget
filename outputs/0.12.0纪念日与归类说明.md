# 0.12.0 纪念日详情与周期倒数日归类

直接覆盖安装，打开应用刷新。

## 纪念日显示

每条纪念日增加第二行信息：

- 第一行：名称和累计天数。标题包含“结婚”“婚礼”或“领证”时显示“已婚N天”，其他显示“已过N天”。原始日期未到则显示“还有N天”。
- 第二行：原始日期和下次周年倒计时。桌面采用紧凑文案，例如“2023-06-18 ·距4周年242天”；周年当天显示“今天N周年”。应用内显示完整说明。

累计天数一直从原始日期计算，不会在周年日清零。请在小米日历里填写真实起始年份；如果原记录填写的是今年的周年日期，应用不能推断真正的结婚年份。

纪念日每条占两行，桌面会根据高度减少纪念日栏的可见条数，其他栏仍为原来的单行。可长按拉高组件，设置上限仍为每列15条。三列较窄时名称和详情会缩小或省略；完整日期及周年说明可在应用中查看。

## 周期倒数日归入纪念日

进入应用，点击“周期倒数日归入纪念日…”，逐条勾选希望归类的每月/每年重复倒数日，点击“应用”。

被选中的项目只出现在纪念日栏，不再重复出现在周期倒数日栏。取消勾选后恢复原栏。归类只保存在本应用，原日历记录、重复规则及提醒均不修改。

归入后按原始日期计算累计天数和年度周年；公历每月重复项目也按年度周年展示，不是按下一次月度日期计算。农历年度记录使用小米提供的年度rdate；如果没有可用年度日期（包括农历每月重复记录），仍显示累计天数，但周年标注“待同步”，不会猜算。
