# 0.10.0 扩大光晕调节范围

- 光晕范围由40–120%扩大到20–240%。
- 颜色消散速度由1–5扩大到1–10。
- 新增横向位置0–100%、纵向位置0–100%，整组颜色可从卡片一边移动到另一边。
- 新增“重置光晕位置与范围”，恢复0.9.0默认样式。

覆盖安装后，打开应用的“配色与外观”，松开滑块即可应用。旧的强度、范围和其他设置保留，不会自动改变当前外观。

使用小部件共用的像素代码验证：默认强度下，最大范围的有效着色面积约为最小范围的32倍；横向/纵向位置调节产生明显的重心位移。实际可见面积也受边缘裁切、强度、消散速度和透明度影响。

此更新针对柔彩光晕，自定义照片仍使用独立的图片缩放与位置设置。已完成范围效果检查、APK编译、签名与对齐检查。
