# 0.16.0 点击区域修正

直接覆盖安装 XiaomiCountdown-0.16.0.apk，保持三列独立滚动和原有配色。

- 点击标题、事项、空列的“暂无”、空列下方整块区域、短列表下方的留白，均打开小米日历首页。
- 列表内容少时只占实际内容高度，剩余区域交给列容器接收点击；空列使用铺满该列的可点击空状态。
- 保留上下滑动查看列表。长按仍由桌面处理。
- 删除纪念日旁的“↗”。旧图标实际上触发手动刷新，不代表查看事项或展开。应用内仍有“授权 / 刷新”，自动更新机制保持不变。
- 不再向日历入口附带事件ID，事项与留白使用相同的日历入口。

验证：APK编译、签名和对齐检查；本地日期、重复、布局和光晕规则测试。Android仪器检查补充短列表留白、空列点击入口、箭头移除、滚动与不截断检查，已编译，未在设备上执行。HyperOS实际点击和滑动效果仍需真机确认。
